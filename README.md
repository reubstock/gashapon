# Gashapon

WebGL gashapon machine experiment — a 3D capsule-toy vending machine in the top half, a 3×3 grid of collectibles below.

Built with vanilla [Three.js](https://threejs.org/) — no build step, single HTML file.

## Series 01 — Serial Killers

Nine satirical kitsch vinyl figures stylized after iconic visual identifiers.
No graphic content depicted.

## Running locally

```sh
# any static server works
python3 -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` in a browser.
